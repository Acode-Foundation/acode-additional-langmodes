# Changelog

## v1.1.5

- Added a Makefile mode 

## v1.1.4

- Added an enhanced YAML/YML mode with structural parsing, richer scalar highlighting, indentation, and folding.

## 1.1.3

- Added git commit message mode (`^COMMIT_EDITMSG`, `^commit_editmsg`)

## 1.1.2

- Added gleam language support

## 1.1.1

- Added gitattributes modes and fixed indentation issue of ejs mode

## 1.1.0

- Added new modes:
    - Jsonc
    - Assembly
    - ASCIIDoc
    - Ejs

## 1.0.1

- fixed bibtex mode issue

## 1.0.0

- Add AutoHotkey v1/v2 language support.
- Add Zig and ZON language support.
- Add Git ignore language support.
- Add missing CodeMirror community modes for BibTeX, Elixir, GolfScript,
  GraphQL, Graphviz DOT, HCL, J, Janet, Pkl, Svelte, and WGSL.
